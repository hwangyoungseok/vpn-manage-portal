# Legacy VPN 시연 확인 체크리스트

- **일시**: 2026-10-07 오전 10:00 (한국 시간)
- **진행 방식**: Teams 미팅, 기존 Legacy VPN 서비스 시연
- **목적**: 현재 운영 흐름과 실제 관리 항목을 확인하고 RemoteHub 요구사항 및 목업 수정 사항을 정리한다.
- **참조**: [RemoteHub 요구사항](./00-requirements.md), [목업 사용 안내](../mockup/README.md)

이 문서는 미팅에서 확인할 질문을 정리한 자료다. Legacy 서비스의 실제 동작과 새 시스템의 확정 요구사항은 미팅 결과로 기록한다.

## 1. 미팅에서 우선 확인할 내용

**신청 한 건이 계정·ACL·IP에 어떻게 반영되는지**, 그리고 **운영자가 직접 처리하는 부분이 무엇인지**를 중심으로 확인한다. 시연 중 화면 순서, 필수 입력값, 처리 결과를 확인하는 위치를 기록한다.

- [ ] 신규 신청부터 실제 반영까지의 처리 흐름을 확인했다.
- [ ] 운영자가 직접 처리하는 단계와 자동 처리되는 단계를 구분했다.
- [ ] 자주 사용하는 화면·필드·버튼을 확인했다.
- [ ] 실패·예외 상황의 확인 및 재처리 방법을 확인했다.
- [ ] 현재 방식 중 유지할 것과 개선할 것을 구분했다.

## 2. 요청할 시연 순서

### 2.1. 신규 등록

신청 접수 → 계정 생성 → ACL 적용 → IP 할당 → 처리 결과 확인

- [ ] 신청이 어디서 들어오고 어떤 정보가 전달되는지 확인한다.
- [ ] 누가 승인하고 계정·정책을 적용하는지 확인한다.
- [ ] 기존 ACL 매핑과 새 ACL 생성 방식을 확인한다.
- [ ] VPN·AD에 정상 반영됐는지 확인하는 방법을 확인한다.

### 2.2. 기존 계정 변경

기간 연장, ACL 추가·제거, 사용자 정보 변경

- [ ] 계정 상세에서 수정할 수 있는 항목과 변경할 수 없는 항목을 확인한다.
- [ ] 기간 연장 및 정책 변경 시 신청 근거가 필요한지 확인한다.
- [ ] 공유 ACL 수정 시 다른 계정에 미치는 영향을 확인한다.
- [ ] 변경 내역과 처리 결과를 어디서 조회하는지 확인한다.

### 2.3. 삭제·실패 처리

계정 삭제와 삭제 이력, 연동 실패 시 확인·재처리

- [ ] 계정 사용 중지와 삭제의 차이, VPN·AD 처리 범위를 확인한다.
- [ ] 요청 삭제·기간 만료·장기 미접속 삭제를 어떻게 구분하는지 확인한다.
- [ ] 일부 시스템에만 반영된 경우 화면에 어떻게 표시되는지 확인한다.
- [ ] 재시도와 수동 복구 절차를 확인한다.

## 3. 화면·운영 확인 질문

| 확인 항목 | 미팅에서 물어볼 내용 | 관련 목업 화면 |
|---|---|---|
| 신청·처리 흐름 | 신청은 어디서 들어오는가? 누가 승인하고 적용하는가? 실제 처리 상태와 일괄 처리 방식은 무엇인가? | 신청 목록 |
| 계정 상세 | 운영자가 꼭 확인하는 필드와 자주 사용하는 버튼은 무엇인가? VPN 계정과 AD 계정은 어떻게 연결되는가? | 계정·정책 목록, 계정 상세 |
| ACL 구조 | 계정 전용 ACL과 공유 ACL을 어떻게 구분하는가? 이름 규칙, 목적지·포트 형식, 허용/차단·우선순위가 있는가? | 계정 상세, 그룹 ACL |
| 공유 ACL 변경 | 공유 ACL을 수정하면 적용 중인 모든 계정에 바로 반영되는가? 사용 중인 ACL 삭제는 어떻게 처리하는가? | 그룹 ACL, 계정 상세 |
| 그룹사·IP | 그룹사 구분은 필터인가, 접근 권한까지 분리하는가? 고정 IP는 자동/수동 중 어떤 방식이며 중복·회수는 어떻게 관리하는가? | 그룹사 관리, IP 대역·고정 IP |
| 만료·미접속 | 만료 시 사용 중지와 삭제 중 무엇을 하는가? VPN·AD에 각각 어떻게 반영되는가? 예외 계정과 알림 기준은 무엇인가? | 계정 상세, 삭제 사용자 |
| 연동·오류 | VPN에는 반영됐지만 AD에서 실패하면 화면에 어떻게 표시되는가? 재시도와 수동 복구가 가능한가? | 신청 목록, 계정 상세, 감사 로그 |
| 관리자·보안 | 운영자에게 실제로 허용되는 기능은 무엇인가? MFA·잠김 해제·접속 허용 IP를 어디서 관리하는가? | 로그인, 관리자, 권한 |
| 로그·리포트 | 누가 무엇을 변경했는지 어느 수준까지 남는가? 보고서·엑셀에서 꼭 필요한 항목과 집계 기준은 무엇인가? | 감사 로그, 월간 리포팅, 계정 목록 |
| 기존 운영의 불편 | 가장 자주 하는 작업, 시간이 많이 드는 작업, 실수가 잦은 작업은 무엇인가? | 관련 화면과 작업 순서를 기록 |

## 4. 미결 요구사항 확인

현재 요구사항에서 미정이거나 추가 확인이 필요한 항목이다. 기존 운영 방식과 새 시스템에서 원하는 방식을 각각 확인한다.

| 항목 | 확인할 내용 | 요구사항 참조 | 확인 결과 |
|---|---|---|---|
| VPN 장비 및 API | 장비 모델·버전, API 문서 제공 여부, 지원 기능 | §1.2 | 미확인 |
| 신청 연계 데이터 | 필드, 고유번호, 근거 시스템·번호, 중복 신청 처리 기준, 데이터 샘플 | §1.1, §2 | 미확인 |
| AD 연동 | 연동 방식, OU·그룹·attribute 매핑, 정상 반영 확인 방법 | §1.3 | 미확인 |
| 생산 협력사 삭제 기준 | 미접속 삭제 기준이 실제로 1년인지, 예외가 있는지 | §7의 `1년?` | 미확인 |
| VIP 기한·삭제 기준 | 최대 사용 기한과 미접속 삭제 기준, 예외 처리 | §3, §7, §12.1 — 기한 표에 VIP 없음 | 미확인 |
| AIP 파일 처리 | 업로드 복호화·다운로드 암호화 방식, Agent 제공 범위 | §10 | 미확인 |
| 기존 데이터 이관 | 계정·ACL·IP·삭제 이력·감사 이력의 이관 범위와 자료 제공 여부 | 추가 확인 항목 | 미확인 |
