# RemoteHub 요구사항

## 1. 시스템 연계

### 1.1. 신청 시스템 연동

- EAI 연동 (현재 EAI 연계 데이터)
- API 연동
- 연동 필요 항목 정의 필요

### 1.2. VPN 장비 연동

- API 연동
- 연동 필요 항목 정의
- 신규 계정 생성 및 정책 생성
  - ACL 이름을 새로 만들고 해당 ACL 내에 필요한 IP/포트 정보를 삽입하는 방식
  - 또는 기존 ACL을 해당 계정 정책에 매핑하는 방식
- 기존 계정 내 정책 수정
- 계정 삭제
- 그룹 ACL (미리 정의한 ACL) 신규 생성·수정·삭제 로직 필요
  - 해당 ACL 이름은 신청 시스템과도 연계 필요
- 정상 동작 여부 확인 로직 필요
- 배치를 실행하여 전일 사용자 접속 및 마지막 접속일 확인
  - 배치가 정상 실행되지 않았을 경우, 실행되지 않았던 배치 재확인 로직 필요

### 1.3. AD 연동

- LDAP? 연동
- 신청 시스템으로 신규 사용자가 들어올 시 신규 계정 생성·삭제 필요
- 비밀번호 임의 설정 로직 필요
- 계정 신청 시 특정 OU (조직) 내 계정 생성·수정 필요
  - 이 과정에서 OU 신규 생성이 필요할 수 있음
- OU 외 특정 `memberOf` 내 사용자 추가·삭제 기능 (추가)
- 정상 반영 여부 확인 로직 필요
- 특정 attribute에 값 반영 (IP 주소, OTP 사용 여부 등)

### 1.4. 이메일 발송 연동

- 미사용 계정 삭제 7일 전 및 1일 전 알림 메일 발송
- 계정 생성 완료 메일 발송
- 삭제 메일 발송

## 2. 신청 목록 확인 및 정책 적용

- 연계된 시스템에서 넘어온 목록 확인 및 정책 적용
- 엑셀 업로드
- 근거 시스템, 근거 번호, ...

## 3. 적용 목록 확인 및 정책 확인

- 엑셀로 목록 다운로드 가능
- 다운로드 내역 로깅
- 다운로드 목록 내 개인정보 제외
  - 메일, 전화번호 등 불필요
  - 계정, 정책, 만료 기한 등 필요
- 사용자 구분: 협력사, 정직원, VIP

## 4. 그룹사 관리

- 사용 그룹사 관리
- 그룹사별 사용자·정책 별도 관리

## 5. 그룹사별 IP 대역 관리

## 6. 그룹사별 IP 대역 내 고정 IP 할당

- 고정 IP 할당 로직 필요

## 7. 계정 기한 만료 및 사용자 통보

- 계정 기한 만료 기능 및 이에 따른 사용자 통보 기능 필요 (메일 연동 필요)
- 사용자 구분에 따라 만료 기한이 달라짐

| 사용자 구분 | 계정 최대 기한 | 미접속 시 계정 삭제 기준 |
|-------------|----------------|-------------------------|
| 협력사 | 6개월 | 3개월 이상 미접속 |
| 정직원 | 1년 | 6개월 이상 미접속 |
| 생산 협력사 | 1년 | 1년? |

- 요건이 있을 시 사용자 구분 추가 및 삭제 기한 변경 가능 로직 추가

## 8. 삭제 사용자 목록 및 사유 확인

## 9. 관리자 계정 생성·삭제 및 권한 관리

- 권한은 Admin, 운영자로 역할 분리 필요
- 관리자: 전체 권한
- 운영자:
  - 계정 생성·삭제
  - 정책 생성·삭제
  - IP 할당
  - 목록 확인 등
  - 관리자 생성·삭제 권한 불필요
- 비밀번호: 8자 이상, 소문자·대문자·특수문자 3개 이상 포함
- 비밀번호 5회 이상 오류 시 계정 잠김 기능
- 타 관리자 비밀번호 해제 가능
- 특정 IP에서만 해당 시스템 접속 권한 부여
  - 접속 가능 IP 관리 페이지 필요

## 10. 보안

- 비밀번호 암호화
- 사용자 이름 가운데 마스킹 처리
- 파일 업로드 시 암호화 해제 / 다운로드 시 암호화 적용
  - AIP 암호화 Agent?는 제공
- 로그인 시 MFA 적용

## 11. 관리자 로깅 및 행위 내용 확인

- 관리자 로깅 필요
- 행위 내용 확인 필요 (어떤 정책·사용자 등을 생성·삭제했는지 등)

## 12. 월간 사용자 리포팅 페이지

### 12.1. 회사별 사용자 현황

- 회사별 사용자 수: 전체, VIP, 정직원, 협력사
- 전월 증감
- 신규 등록 건수
- 삭제 건수는 다음 사유별로 구분하여 표기
  - 요청 삭제
  - 기간 만료 삭제
  - 장기 미사용 삭제

### 12.2. 월간 변경 관리 현황

- 신청 시스템별 건수 집계
  - 신규
  - 기간 연장
  - 삭제
  - 정책 추가
  - 정책 삭제
  - 정책 변경
  - 정보 변경 등
- 회사별로도 별도 표기 필요
