# AD 연동 방식 확인 메일 초안

**제목:** RemoteHub AD 연동 방식 및 사용자 데이터 원천 확인 요청

안녕하세요.

지난 회의에서 논의한 AD 연동 범위를 확인하고자 합니다. 현재 저희는 **로그인 인증은 VPN 환경의 로컬 AD에서 처리**하고, 계정 생성·변경 등에 필요한 사용자 정보와 연동 데이터는 **신청 시스템에서 전달받아 VPN AD 및 관련 시스템에 반영**하는 구조로 이해하고 있습니다. 회의에서는 **다른 AD와 실시간으로 연동해 사용자 데이터를 받아오는 구조**도 언급되어, 실제 요구하시는 방식을 확인 부탁드립니다.

1. 로그인 인증은 어느 AD에서 처리하나요? 여기서 말하는 로그인은 VPN 사용자 로그인과 RemoteHub 관리자 로그인 중 각각 어디에 해당하나요?
2. 사용자 정보의 원천은 신청 시스템인가요, 다른 AD인가요? 각각 어떤 정보(계정·조직·그룹·속성 등)를 제공하고 어느 시스템에 반영해야 하나요?
3. AD 간 실시간 연동이 필요하다면, 연동 대상과 방향(읽기/쓰기 또는 양방향), 데이터 반영 시점, 연동 방식(API/LDAP/동기화 등), 담당 시스템을 알려주실 수 있나요?
4. 신청 정보와 AD 정보가 다르거나 연동이 실패하면 어느 데이터를 기준으로 처리하고, 재시도·수동 처리 책임은 어디에 있나요?

회신 내용을 바탕으로 신청 시스템 연계와 AD 연동의 범위, WBS 및 공수를 구분해 정리하겠습니다.

감사합니다.
